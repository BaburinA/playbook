В вашей команде запуска вы использовали относительный путь ("Desktop\PS\..."). Если вы запускаете PowerShell не из корня диска C:\, он не найдет файл.
Всегда используйте абсолютный путь (полный путь от диска). Правильная команда для вашего случая:
powershell
1 powershell.exe -ExecutionPolicy Bypass -File "C:\Users\baburin_ag\Desktop\PS\Install-Printer.ps1"
Или еще проще:
Просто кликните по файлу Install-Printer.ps1 правой кнопкой мыши и выберите "Run with PowerShell" (Запустить с помощью PowerShell). Скрипт сам запросит права админа и отработает.

Исправить кодировку файла (Рекомендуется)
Вам нужно пересохранить файл .ps1 в кодировке UTF-8 с BOM (или просто UTF-8 в новых версиях Блокнота).
Если у вас Windows 10 или 11 (Стандартный Блокнот):
Откройте ваш файл Install-Printer.ps1 в Блокноте.
Нажмите Файл -> Сохранить как... (File -> Save As).
Внизу окна найдите выпадающий список Кодировка (Encoding).
Выберите UTF-8 (в новых версиях Windows это автоматически означает UTF-8 с BOM). Не выбирайте ANSI!
Сохраните файл, заменив старый.
Если у вас Notepad++ или VS Code:
Откройте файл.
В нижнем меню или в меню "Кодировки" (Encoding) выберите UTF-8 with BOM (UTF-8 с BOM).
Сохраните файл.
